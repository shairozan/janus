# Opensourcing Janus
The goal here is to effectively remove:

* All references to the licensing service
* All need for a license during startup
* The actual signature process should still work but should bind to a local keychain instead
* All source validation documentation should be removed
* Plan documentation referring to Pharmalytica
* Usage of any pharmalytica repo
    * Hermes has already been moved to shairozan/hermes and is OPEN now. Requires no auth.
